# M0 Foundations: implementation plan

Status: **Draft for human review** (architect, 2026-10-17). Skill: `implement-milestone`, step 3.

## Goal
Set up a buildable, linted, license-clean Cargo workspace with CI on Windows and Linux. Add a
dependency-rule check that is proven to fail on violations. Add a `cgf-core` skeleton with IDs, time
and units. Everything later milestones build on is enforced here: inward dependencies, no `unsafe`
outside FFI crates, no wall clock or hash-order hazards, and license hygiene.

**Acceptance (spec section 17, M0):**
1. CI is green on Windows and Linux.
2. The dependency-rule check fails when a rule is violated, and a test proves it.

**Gate check (step 1):** M0 is the first milestone, so there is no earlier milestone to check.

## Design overview

### Workspace layout after M0
```
Cargo.toml              # [workspace], [workspace.package], [workspace.dependencies], [workspace.lints]
Cargo.lock              # committed (CI uses --locked)
rust-toolchain.toml
clippy.toml
deny.toml
.cargo/config.toml      # alias: xtask = "run --package xtask --"
.gitattributes .gitignore
LICENSE-MIT LICENSE-APACHE
.github/workflows/ci.yml
crates/cgf-core/        # lib, forbid(unsafe_code)
xtask/                  # bin + lib (check-deps), tests/fixtures/* (separate mini-workspaces)
docs/architecture.md docs/build.md
```
Placeholders: **none** (ASM-010). The negative test does not need real forbidden crates, because it uses
fixture workspaces. The rule table already lists every section 4 crate, so each new crate is covered as
soon as it is added. A crate that is missing from the table fails the check.

### Dependency-rule check (`xtask`)
The check is a pure function plus a thin loader. The rules are data (ASM-005..009).

```rust
// xtask/src/deps/mod.rs
pub enum DepKind { Normal, Build, Dev }

pub struct DepEdge {
    pub from: String,          // workspace package name
    pub to: String,            // real package name (rename resolved)
    pub kind: DepKind,
    pub target: Option<String>,// cfg(...) for target-specific deps
    pub is_workspace: bool,    // to is a workspace member (ASM-006)
}

pub struct WorkspaceGraph {
    pub members: std::collections::BTreeSet<String>,
    pub edges: Vec<DepEdge>,
}

pub struct CrateRule {
    pub name: &'static str,
    pub allowed_workspace_deps: &'static [&'static str],
    pub allow_external_deps: bool,   // false only for cgf-plugin-api (normal + build)
    pub requirement: &'static str,   // "REQ-A-1", "REQ-A-2", "REQ-A-3", "section 4"
}

pub struct RuleSet { pub crates: &'static [CrateRule] }
pub const RULES: RuleSet = /* full section 4 table, see below */;

#[derive(Debug, PartialEq, Eq, PartialOrd, Ord)]
pub enum Violation {
    UnknownCrate { name: String },
    ForbiddenWorkspaceDep { from: String, to: String, kind: DepKind, requirement: &'static str },
    ExternalDepNotAllowed { from: String, to: String, kind: DepKind },
}

/// Pure and deterministic: the result is sorted.
pub fn check(graph: &WorkspaceGraph, rules: &RuleSet) -> Vec<Violation>;

#[derive(Debug, thiserror::Error)]  // or anyhow at the binary edge only
pub enum LoadError { /* cargo metadata failed, bad JSON */ }

/// Runs `cargo metadata --no-deps --format-version 1 --manifest-path <p>` (offline, no resolution).
pub fn load_graph(manifest_path: &std::path::Path) -> Result<WorkspaceGraph, LoadError>;
```
- CLI: `cargo xtask check-deps [--manifest-path <path>]`. It prints one line per violation, for example
  `REQ-A-1: cgf-core -> cgf-kernel (normal) not allowed; cgf-core may depend on: (none)`. It exits with 1
  on any violation, 2 on a load error and 0 when clean.
- Rule table (allowed workspace deps):

| Crate | Allowed workspace deps | External deps |
|---|---|---|
| cgf-core | none | yes |
| cgf-kernel | core | yes |
| cgf-motion, cgf-behavior, cgf-templates, cgf-net | core | yes |
| cgf-plugin-api | none | **no** (normal/build) |
| cgf-plugin-host | core, plugin-api | yes |
| cgf-sdk | plugin-api | yes |
| cgf-net-dis, cgf-net-hla | sdk | yes |
| cgf-engine | core, kernel, motion, behavior, templates, plugin-api, plugin-host, net | yes |
| cgf-api-types | none | yes |
| cgf-server | engine, api-types | yes |
| cgf-cli | engine, server | yes |
| xtask | none | yes |

  `examples/plugins/*` (rule: sdk only) is added in M4, when the first example exists.
- Self-test on the table: the allowed graph is acyclic. The transitive closure of `cgf-kernel` contains
  no `cgf-server`, `cgf-net-*` or `cgf-api-types` (REQ-A-2). The closure of `cgf-sdk` is exactly
  `{cgf-plugin-api}` (REQ-A-3). The closure of `cgf-core` is empty (REQ-A-1). Every name in an allow-list
  is itself a key in the table.

### `cgf-core` skeleton (public API, signatures only)
Module layout: `lib.rs` (crate docs: responsibility, REQ-IDs, `#![forbid(unsafe_code)]`), `units.rs`,
`time.rs`, `id.rs`. External dependency: `thiserror` only.

**Units (REQ-C-4, ASM-015)**
```rust
#[derive(Debug, Clone, Copy, PartialEq, PartialOrd, Default)]
pub struct Meters(pub f64);
// same derive set for:
pub struct Seconds(pub f64);
pub struct Radians(pub f64);
pub struct Kilograms(pub f64);
pub struct MetersPerSecond(pub f64);
pub struct MetersPerSecondSquared(pub f64);
pub struct RadiansPerSecond(pub f64);

// Same-type ops for every unit X: Add<X>, Sub<X>, Neg, Mul<f64>, Div<f64>, Div<X> -> f64 (ratio),
//   AddAssign, SubAssign. One private macro implements them (DRY).
// Cross-type ops (only these):
impl Mul<Seconds> for MetersPerSecond        { type Output = Meters; }
impl Div<Seconds> for Meters                 { type Output = MetersPerSecond; }
impl Mul<Seconds> for MetersPerSecondSquared { type Output = MetersPerSecond; }
impl Div<Seconds> for MetersPerSecond        { type Output = MetersPerSecondSquared; }
impl Mul<Seconds> for RadiansPerSecond       { type Output = Radians; }
impl Div<Seconds> for Radians                { type Output = RadiansPerSecond; }

impl Radians {
    pub fn from_degrees(deg: f64) -> Self;
    pub fn to_degrees(self) -> f64;
}
impl RadiansPerSecond {
    pub fn from_degrees_per_second(dps: f64) -> Self;
    pub fn to_degrees_per_second(self) -> f64;
}
```

**Time (REQ-C-1, ASM-016)**
```rust
/// Fixed simulation tick rate in whole hertz (D-5).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct TickRate(core::num::NonZeroU32);
impl TickRate {
    pub const fn new(hz: u32) -> Option<Self>;   // None for 0
    pub const fn hz(self) -> u32;
    pub fn dt(self) -> Seconds;                  // 1.0 / hz
}

/// Simulation time: an integer tick count at a fixed rate. Not related to wall-clock time.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct SimTime { tick: u64, rate: TickRate }
impl SimTime {
    pub const fn start(rate: TickRate) -> Self;                 // tick 0
    pub const fn at_tick(rate: TickRate, tick: u64) -> Self;
    pub const fn tick(self) -> u64;
    pub const fn rate(self) -> TickRate;
    pub fn dt(self) -> Seconds;
    pub fn as_seconds(self) -> Seconds;                         // tick as f64 / hz as f64
    pub fn checked_next(self) -> Option<Self>;                  // None on u64 overflow
    pub fn checked_advance(self, ticks: u64) -> Option<Self>;
    pub fn ticks_since(self, earlier: SimTime) -> Result<u64, TimeError>;
}
/// Ordering is defined only for equal rates.
impl PartialOrd for SimTime { /* None when rates differ */ }

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
#[non_exhaustive]
pub enum TimeError {
    #[error("tick rates differ: {left} Hz vs {right} Hz")]
    RateMismatch { left: u32, right: u32 },
    #[error("time {to} is before {from}")]
    NegativeInterval { from: u64, to: u64 },   // from = argument of ticks_since, to = receiver
}
```
There is no `Clock` and no wall-clock access here (ASM-018). The kernel advances `SimTime` in M1.

**IDs (REQ-C-2, ADR 0002 accepted, ASM-017)**
```rust
/// Engine-unique entity id; never 0; never reused within a run (allocation is in the kernel, M1).
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct EntityId(core::num::NonZeroU64);
impl EntityId {
    pub const fn new(raw: u64) -> Option<Self>;
    pub const fn get(self) -> u64;
}
impl core::fmt::Display for EntityId { /* decimal */ }

// One private macro generates each of: TemplateId, BehaviorId, MotionModelId, PluginId.
// Each one validates through one shared private fn (DRY).
#[derive(Debug, Clone, PartialEq, Eq, Hash, PartialOrd, Ord)]
pub struct TemplateId(std::sync::Arc<str>);
impl TemplateId {
    pub fn new(s: &str) -> Result<Self, IdError>;
    pub fn as_str(&self) -> &str;
}
impl core::str::FromStr for TemplateId { type Err = IdError; }
impl TryFrom<&str> for TemplateId { type Error = IdError; }
impl TryFrom<String> for TemplateId { type Error = IdError; }
impl core::fmt::Display for TemplateId {}
impl AsRef<str> for TemplateId {}

pub const MAX_ID_LEN: usize = 128;

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum IdError {
    #[error("id is empty")]                                   Empty,
    #[error("id {id:?} is {len} bytes; max is {max}")]        TooLong { id: String, len: usize, max: usize },
    #[error("id {id:?} needs at least two dot-separated segments")] MissingNamespace { id: String },
    #[error("id {id:?} has an empty segment at byte {index}")] EmptySegment { id: String, index: usize },
    #[error("id {id:?} has invalid character {ch:?} at byte {index}")] InvalidChar { id: String, ch: char, index: usize },
    #[error("id {id:?}: segment at byte {index} must start with a-z")] InvalidSegmentStart { id: String, index: usize },
}
```
`Ord` is byte-lexicographic, so these IDs are deterministic keys in `BTreeMap` (REQ-K-4). The
`TooLong` message reports a prefix of the ID only, so error text stays bounded.

### Lint, format and supply-chain configuration
- `[workspace.lints.rust]`: `unsafe_code = "deny"`, `missing_docs = "warn"`.
- `[workspace.lints.clippy]`: `pedantic = { level = "warn", priority = -1 }` plus a short allow-list,
  `unwrap_used`, `expect_used`, `dbg_macro`, `todo`, `print_stdout` (libraries) at `warn`. CI uses
  `-D warnings` (ASM-012).
- `clippy.toml`: `allow-unwrap-in-tests = true`, `allow-expect-in-tests = true`, `disallowed-methods`
  (`SystemTime::now`, `Instant::now`), `disallowed-types` (`HashMap`, `HashSet`) (ASM-013).
- No `rustfmt.toml` (section 16: rustfmt defaults).
- `deny.toml`: `[graph] targets = [x86_64-pc-windows-msvc, x86_64-unknown-linux-gnu]`. `[advisories]`:
  yanked = deny. `[licenses]`: the allow-list from ASM-020, `confidence-threshold = 0.9`. `[bans]`:
  `wildcards = "deny"` with `allow-wildcard-paths = true`, `multiple-versions = "warn"`. `[sources]`:
  unknown registry and unknown git = deny.
