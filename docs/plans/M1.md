# M1 Walking skeleton: implementation plan

Status: **Draft for human review** (architect, 2026-10-17). Skill: `implement-milestone`, step 3.
Base: `develop` at 4542b0b (tag `m0-done`).

## Goal
A headless, deterministic tick loop that moves one hard-coded ground entity (plus two more for the
determinism test) along a waypoint list, prints its state from the CLI, and produces a per-tick state
hash. The pieces built here are the ones every later milestone sits on: the clock, the ECS world and
fixed phase pipeline, `SimRng`, coordinates, the math module, the `MotionModel`/`TerrainProvider`
traits and the `builtin.ground.kinematic` model.

**Acceptance (spec section 17, M1):**
1. The determinism test passes (gate 4, `cargo test -p cgf-engine --test determinism --locked`).
2. The coordinate tests pass (reference values with sources, plus round-trip properties).
3. An entity follows a waypoint list.

**Gate check (step 1):** M0 is ticked in `docs/milestones.md` with evidence (tag `m0-done`). Acceptance 1
there was waived by ADR 0004; the local gate in `docs/build.md` is the definition of done.

**Spec section 19 Q2 (resolved by the human, 2026-10-17):** A-1 is confirmed as written (up to ~10,000
owned entities at 10-60 Hz, one simulation thread, NFR-1 target unchanged). A-2 is confirmed with the
ADR 0003 scope: bit-identical state hashes on the same OS, enforced by the determinism gate from M1.
The coordinator marks Q2 resolved in `docs/SPEC.md`. Effect on this plan: none beyond what is designed
below (single-threaded pipeline, per-OS hash equality, math module ready for a later `libm` swap).

### `cgf-core::math` (ADR 0003, ASM-034)

### `cgf-core::coords` (REQ-C-3, D-15, ASM-033)
```rust

/// User-facing position (human requirement 2026-10-17, ASM-044): either form is accepted at the API edge
/// and converted to ECEF exactly once; nothing behind the edge stores or computes in geodetic.
#[derive(Debug, Clone, Copy, PartialEq)]

impl Position { pub fn to_ecef(self) -> Ecef; }
impl From<Ecef> for Position {}  impl From<Geodetic> for Position {}
#[derive(Debug, Clone, Copy, PartialEq)] pub struct Enu { pub east: f64, pub north: f64, pub up: f64 }
#[derive(Debug, Clone, Copy, PartialEq)] pub struct Ned { pub north: f64, pub east: f64, pub down: f64 }
impl From<Enu> for Ned {}  impl From<Ned> for Enu {}   // exact axis swaps

/// Local tangent plane at `origin`. Built once (one sin_cos per angle), reused for many points.
pub struct LocalFrame { origin: Ecef, geodetic: Geodetic, ecef_from_enu: [[f64; 3]; 3] }
impl LocalFrame {
  pub fn at(origin: Geodetic) -> Self;
  pub fn origin(&self) -> Ecef;
  pub fn to_enu(&self, p: Ecef) -> Enu;          pub fn from_enu(&self, e: Enu) -> Ecef;
  pub fn to_ned(&self, p: Ecef) -> Ned;          pub fn from_ned(&self, n: Ned) -> Ecef;
  pub fn vector_to_enu(&self, v: Vec3) -> Enu;   pub fn vector_from_enu(&self, e: Enu) -> Vec3;   // rotation only
  pub fn orientation_from_euler(&self, e: Euler) -> Quaternion;   // body (FRD) -> ECEF
  pub fn euler_from_orientation(&self, q: Quaternion) -> Euler;
}
#[derive(Debug, Clone, PartialEq, thiserror::Error)] #[non_exhaustive]
pub enum CoordError { #[error("latitude {0} rad outside [-pi/2, pi/2]")] LatitudeOutOfRange(f64),
                      #[error("non-finite coordinate")] NonFinite }
```
`Ecef::to_geodetic` uses a closed-form method with no data-dependent iteration count (Heikkinen 1982 as
given by Zhu 1994, IEEE Trans. AES 30(3)), with an explicit polar-axis branch (`p == 0`) and a finite
result at the centre. It is infallible and returns finite values for every finite input. Accuracy targets
are in AT-3. If the closed form misses them, one fixed Newton correction step is allowed (still no loop).

### `cgf-motion::ground` (REQ-M-2, ASM-030, ASM-031)
```rust
pub const GROUND_KINEMATIC_ID: &str = "builtin.ground.kinematic";   // ADR 0002
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct GroundKinematicParams { pub max_speed: MetersPerSecond, pub max_turn_rate: RadiansPerSecond, pub max_accel: MetersPerSecondSquared }
pub struct GroundKinematic { id: MotionModelId, params: GroundKinematicParams }
impl GroundKinematic { pub fn new(params: GroundKinematicParams) -> Result<Self, MotionParamError>; pub fn params(&self) -> GroundKinematicParams; }
impl MotionModel for GroundKinematic { /* ... */ }
#[derive(Debug, Clone, PartialEq, thiserror::Error)] #[non_exhaustive]
pub enum MotionParamError { #[error("{name} must be finite and > 0, got {value}")] NotPositive { name: &'static str, value: f64 } }
```
Algorithm, per step (all trig through `cgf_core::math`):
1. `g = position.to_geodetic()`, `frame = LocalFrame::at(g)`; heading from `frame.euler_from_orientation`;
   speed = `|velocity|` (never negative; no reverse in M1).
2. Intent resolution (ASM-030): `Hold` anywhere wins (target speed 0, keep heading); otherwise the last
   `MoveTo` and the last `SetSpeed` win; cruise = `SetSpeed` or `max_speed`, clamped to `[0, max_speed]`;
   no `MoveTo` and no `SetSpeed` = decelerate to 0. Unknown future variants are ignored.
3. With a destination: horizontal ENU offset `d`, bearing `b = atan2(east, north)`, error
   `e = wrap_pi(b - heading)`. Desired speed `v* = min(cruise, sqrt(2 * max_accel * d), max_turn_rate * d / (2 |sin e|))`
   (the last term, skipped when `sin e` is 0, keeps the turning circle able to reach the destination, so
   the entity never orbits it).
4. `speed' = speed + clamp(v* - speed, ±max_accel * dt)`; `heading' = heading + clamp(e, ±max_turn_rate * dt)`.
5. Arrival snap: if a destination exists, `d <= max(speed' * dt, 1 mm)` and `|e| < pi/2`, the new
   horizontal position is the destination and `speed' = 0` (the only step allowed to exceed the
   deceleration limit; bounded by `2 * max_accel` by construction).
6. Otherwise move `speed' * dt` along `heading'` in ENU, convert to ECEF.
7. Terrain following: new geodetic with `height = terrain.height_at(..)`, back to ECEF. Orientation from
   `Euler { heading', pitch: 0, roll: 0 }` in the new position's frame (ASM-032). Velocity = ENU
   `(speed' sin h', speed' cos h', 0)` rotated to ECEF.

```rust
pub struct TickReport { pub time: SimTime /* after the tick */, pub phase_wall: [Duration; 6], pub overrun: Option<Duration> }

// kernel facade
#[derive(Debug, Clone, Copy, PartialEq)] pub struct KernelConfig { pub tick_rate: TickRate, pub seed: u64, pub clock: ClockMode }
pub struct RouteInit { pub waypoints: Vec<Ecef>, pub arrival_radius: Meters, pub cruise_speed: MetersPerSecond }
pub struct EntityInit { pub state: KinematicState, pub ownership: Ownership, pub motion: Arc<dyn MotionModel>, pub route: Option<RouteInit> }
pub struct Kernel { /* clock, world, terrain: Box<dyn TerrainProvider>, rng: SimRng, next_id: u64 */ }
impl Kernel {
  pub fn new(config: KernelConfig, terrain: Box<dyn TerrainProvider>, wall: Box<dyn WallClock>) -> Self;
  pub fn spawn(&mut self, init: EntityInit) -> Result<EntityId, KernelError>;   // between ticks only
  pub fn tick(&mut self) -> Result<TickReport, KernelError>;
  pub fn clock(&self) -> &Clock; pub fn clock_mut(&mut self) -> &mut Clock;
  pub fn now(&self) -> SimTime; pub fn rng(&self) -> SimRng; pub fn entity_count(&self) -> usize;
  pub fn state_hash(&self) -> StateHash;      // ADR 0007 content, EntityId order
  pub fn snapshot(&self) -> Snapshot;
}
#[derive(Debug, Clone, PartialEq)] pub struct Snapshot { pub time: SimTime, pub entities: Vec<EntitySnapshot> }   // sorted by id
#[derive(Debug, Clone, PartialEq)] pub struct EntitySnapshot { pub id: EntityId, pub ownership: Ownership, pub motion_model: MotionModelId, pub state: KinematicState, pub route_next: Option<(usize, usize)> /* (next, len) */ }
#[derive(Debug, thiserror::Error)] #[non_exhaustive]
pub enum KernelError { #[error("simulation time overflow at tick {0}")] TimeOverflow(u64),
                       #[error("entity ids exhausted")] IdsExhausted,
                       #[error("route has no waypoints")] EmptyRoute, /* invalid arrival radius/speed */ }
```
Components (private): `EntityId`, `Ownership`, `KinematicState`, `MotionRef(Arc<dyn MotionModel>)`,
`Intents(Vec<Intent>)` (cleared at the start of Behavior), `Route { waypoints, next, arrival_radius, cruise }`,
`EntityRng(RngStream)` (from `rng.stream(StreamKey::entity(id))` at spawn).
Tick: for each `Phase::ALL` in order, run its systems under a trace-level span and record wall time.
Behavior: route stand-in (Owned only): if horizontal distance to `waypoints[next]` <= arrival radius and
it is not the last, `next += 1`; emit `[SetSpeed(cruise), MoveTo(waypoints[next])]`; after the last
waypoint is reached, emit `Hold`. Motion: for Owned entities, `state = model.step(&state, &intents, dt, terrain)`.
Then `clock.advance()`; if `clock.behind()` is `Some`, `tracing::warn!` with per-phase timings and
`overrun` set in the report. Entity ids start at 1; the counter never decreases (`IdsExhausted` at `u64::MAX`).

## Risks (milestone level)
| Risk | Mitigation |
|---|---|
| Determinism (REQ-K-4) broken by a hidden per-process seed (ECS internals, a dependency) | In-process (AT-1) and cross-process (AT-2) comparisons; hash in `EntityId` order; clippy bans (ASM-042) |
| Determinism broken by wall time leaking into systems | One `WallClock` site (`clock/wall.rs`), systems get only `TickContext`; AT-12 mutation; reviewer greps for `expect(clippy::disallowed_methods` |
| Transcendental math differs between OSes | Accepted for v1 (ADR 0003, Q2 resolved); all calls in `cgf_core::math` so `libm` can be swapped in |
| Wrong coordinate conventions become a DIS bug in M6 | Published reference values (AT-3) and axis tests; conventions in rustdoc |
| Reference values transcribed wrongly | "Verify against source" rule in AT-3/AT-5; analytic points are independent of transcription |
| `MotionModel` trait shape changes when it becomes a plugin kind (M7), affecting ABI stability (REQ-P-2) | Not exposed over the ABI in M1; minimal, object-safe, stateless; revisit in M4/M7 with the plugin-abi-engineer |
| Owned/remote distinction (REQ-K-5) eroded by later shortcuts | `Ownership` on every entity from M1; filter tested (AT-10) |
| Stand-ins (route system, `demo` command, hard-coded scenario) outlive M1 | ASM-027..029 name the milestone that removes or replaces each |
| Dependency weight (criterion, clap) and new licences | Minimal features; `cargo deny` per PR; dev-only where possible |
| No CI: gates 4 and 14 only as good as the local run | `docs/build.md` updated; WI-15 records the full run |
