| ASM-336 | WI-5 components B follow the reference props and `vt-*` classes. (6) `.vt-tab-count` adds `font-variant-numeric: tabular-nums`; `TextField` uses `id || generated` and lets a caller `aria-invalid` through when `invalid` is false. (7) The shared `.vt-label` rule lives in `components/shared/Label.css` (imported by TextField and Slider, ready for Readout). (8) Eight more `umbra-allow` font-size lines copy reference sizes: `.vt-label` 12px, Panel title 16px, Card title 16px, Card subtitle 12px, mono field 13px, help 12px, Slider value 13px, tab count 12px. | ASM-337 | WI-6 components C follow the reference props and `vt-*` classes. Deviations: (1) `CommandBar` (`paused` must be paired by the caller with a visible word, per the JSDoc) is a `header` (the `banner` landmark when a direct child of the body); the clock is `role="timer"` with `aria-label` "Scenario clock" or "Scenario clock, paused" (a bare `aria-label` on a span is not valid, and paused must not be colour only); `brand` defaults to "Umbra" (the reference says "Vantage"; empty string also falls back); `paused` is typed to need a `clock`. Nothing guards other glass children, and the CSS rule has no unit test (happy-dom loads no CSS); the WI-8 screenshot of a floating bar with glass chips is the check. (3) `Readout` is a `dl` (`dt` label, `dd` value, `dd` delta) instead of divs/spans, margins reset; the unit follows the value after U+2009 (the reference used a margin); `trend` is typed to need a `delta`; the trend adds a Material glyph (`trending_up/down/flat`, aria-hidden) and a visually hidden word (Increasing, Decreasing, Unchanged) via the new shared `.vt-visually-hidden` class (`components/shared/VisuallyHidden.css`), because colour must not be the only signal.
